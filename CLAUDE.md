# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

All commands must be run inside the Nix dev shell, which provides gleam, erlang, rebar3, and nodejs:

```bash
nix develop
```

Then:

```bash
# Start dev server with hot reload (port 1234)
gleam run -m lustre/dev start

# Production build
gleam run -m lustre/dev build

# Compile without dev server
gleam build
```

There are no tests. Lustre dev tools use Bun internally under `.lustre/bin/`.

## Architecture

Pure client-side Gleam/Lustre SPA. No backend. All logic runs in the browser.

**The Elm Architecture (TEA):**
- `Model` holds: input text, selected HSK levels (old 1-5 and/or new band 1-3), analysis result, dictionary (loaded from JSON), loading/error state
- Async effect: on init, fetches `assets/dictionary.json` (~13.6 MB CC-CEDICT) via `getOrigin()` from `src/ffi.mjs`
- Analysis triggered on button click: merges HSK word sets → DP segmentation → comprehension % → assessment + top-20 unknown words

**Data flow for analysis:**
1. `known_words_for_levels()` builds a `Set(String)` from HSK sets in `hsk.gleam`
2. `dp_segment()` — greedy dynamic-programming segmenter maximizing coverage by known words (up to 4-char lookups)
3. Filters valid CJK tokens, counts known/total, computes comprehension %
4. `get_assessment()` classifies: <82% TooHard → ... → ≥95% TooEasy
5. Returns top-20 unknown words by frequency with pinyin + definition from dictionary

**Key files:**
- `src/chinese_checker.gleam` — entire app (~810 lines): types, dictionary fetch, segmentation/analysis logic, view, TEA wiring
- `src/hsk.gleam` — auto-generated HSK word sets (8 functions returning `Set(String)`: `hsk1()`–`hsk5()`, `band1()`–`band3()`); regenerated by `tools/generate_hsk_gleam.py`
- `src/ffi.mjs` — single JS FFI export: `getOrigin()`
- `assets/dictionary.json` — preprocessed CC-CEDICT; keys are Chinese words, values are `{"p": pinyin, "d": definition}`
- `assets/css/styles.css` — hand-written CSS, two-column flex layout (260px sidebar + fluid main), responsive at 768px

**Dependencies:** `lustre`, `gleam_stdlib`, `gleam_json`, `gleam_fetch`, `gleam_http`, `gleam_javascript` (runtime); `lustre_dev_tools` (dev only).

## Gleam/Lustre Notes

- `html.option(attrs, "label")` — second arg is String, not children
- `html.textarea(attrs, "content")` — second arg is String
- `event.on_change` for select dropdowns, `event.on_input` for text input
- `gleam_dynamic` is part of `gleam_stdlib`, not a separate package
- Lustre dev server auto-generates HTML; stylesheets configured in `gleam.toml` under `[[tools.lustre.html.stylesheets]]`
- Static assets served from `assets/` directory
